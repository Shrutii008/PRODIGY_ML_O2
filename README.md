# Customer Segmentation using K-Means Clustering

## Task 2 - Prodigy Infotech Machine Learning Internship

---

## 📌 Objective
To segment customers of a retail store based on their purchase behavior using K-Means Clustering.

---

## 📊 Dataset
Mall_Customers.csv

It contains customer information such as:
- Age  
- Annual Income  
- Spending Score  

For clustering, we use:
- Annual Income  
- Spending Score  

---

## 🤖 Algorithm Used
K-Means Clustering (Unsupervised Learning)

It groups similar data points into clusters without using labeled outputs.

---

## ⚙️ Steps Followed
- Loaded dataset using pandas  
- Selected relevant features  
- Applied Elbow Method to find optimal number of clusters  
- Trained K-Means model  
- Visualized customer segments using scatter plot  

---

## 📈 Output
- Elbow Method graph (to find optimal K)  
- Customer segmentation clusters  
- Cluster centroids  

---

## 🛠 Tools Used
- Python  
- Pandas  
- Matplotlib  
- Scikit-learn  

---

## 🚀 Result
Customers are successfully grouped into meaningful clusters based on their spending patterns and income.
